01Overview

Reinforcement learning (RL) in simulation can acquire precise dexterous control, but it relies on privileged state that is unavailable at deployment. Latent RL Prior distills large-scale RL rollouts into a flow-matching action decoder, freezes it, and learns only a visual interface that maps camera images to the decoder’s latent context, using demonstrated actions as the sole supervision.

Abstract

Learning dexterous manipulation from limited visual demonstrations is challenging because policies must acquire both perceptual grounding and precise control, while reinforcement learning (RL) in simulation can acquire rich control behaviors from large-scale interaction with privileged information. We introduce Latent RL Prior, a two-stage framework that reuses this control knowledge for data-efficient visual policy learning. During privileged pretraining, we distill large-scale RL rollouts into a flow-matching action decoder conditioned on proprioception and latent task context. During visual adaptation, we freeze the decoder and learn a visual interface that maps images to its latent context using action supervision alone, without privileged labels or latent targets. The same decoder can further be shared across arms by learning coordinated visual contexts for bimanual manipulation. Across three simulated tasks, our method outperforms full-parameter fine-tuning of π0.5 and GR00T N1.7 in the low-data regime; on door lifting and bimanual assembly, it surpasses full-data baselines using 10× and 5× fewer demonstrations, respectively. Further analysis shows that direct visual-to-latent conditioning improves adaptation performance and training stability over routing visual predictions through the pretrained state encoder. Robustness to unseen mass variation and greater linear accessibility of contact-force information in decoder representations further provide evidence of retained RL-acquired control knowledge. Training and evaluation code and datasets will be released.

Contributions

  1. A transfer framework. A frozen RL action prior is adapted through latent visual conditioning with action supervision alone, and a single-arm decoder is reused for bimanual manipulation.
  2. Demonstration efficiency. Improved visual-demonstration efficiency on three dexterous tasks, with evaluations of the transfer interface and of which modules to adapt.
  3. Evidence of retained control knowledge. Behavioral and representational analyses of robustness to object mass and of contact-force accessibility after visual adaptation.

02Method

Training has two stages that share one action decoder. Task context reaches the decoder through cross-attention, while proprioception and flow time enter through adaptive layer normalization (AdaLN). The source of the context can therefore change from privileged state to images while the pretrained proprioceptive processing and action generation stay intact.

Stage 1

Privileged pretraining

An RL teacher, fine-tuned from the released SimToolReal checkpoint on procedural pose alignment with randomized object shape, size, and density, provides 100,000 successful rollouts.

A state tokenizer and Q‑Former map the privileged history to latent context tokens. A transformer action decoder cross-attends to them and is trained with conditional flow matching.

Trained
state tokenizer, state Q‑Former, action decoder

Stage 2

Visual adaptation

The action decoder is frozen. A DINOv2 image encoder and a visual Q‑Former map camera images directly to the decoder’s context tokens (latent transfer).

Training uses the same flow-matching action loss: no privileged-state labels, no latent targets, and no trajectories paired with the RL data.

Trained
image encoder, visual Q‑Former
Frozen
action decoder

Extension

Two arms, one prior

Each arm receives its own group of queries. Both groups are processed jointly by one visual Q‑Former, so self-attention can coordinate the arms.

The same frozen single-arm decoder then generates each arm’s actions from that arm’s context and proprioceptive history.

Pt: privileged history · It: image history · Rt: proprioceptive history · At: action chunk · τ: flow time. The decoder vθ is trained in stage 1 and frozen afterwards.

03Experimental Setup

All experiments run in MuJoCo Warp with KUKA iiwa arms and SHARPA dexterous hands. A single pretrained action decoder is reused for every downstream task.

Downstream tasks

Single arm · Unseen object

Target pose alignment

Pick up an unseen brush and match its target pose.

Grasp→Reorient→Align

Success criterion. All four object–target keypoint distances must be within 1.5 cm (strict) or 5 cm (relaxed) for 10 policy steps, not necessarily consecutive.

Baselines and protocol

  • VLA baselines. Full-parameter fine-tuning of π0.5 and GR00T N1.7 for 30,000 steps with their officially recommended hyperparameters.
  • Ablations. The same visual architecture trained from scratch (no RL prior), and explicit transfer through the pretrained state encoder.
  • Ours. Latent transfer with a DINOv2-Small (ViT-S/14) image encoder, trained for 100,000 steps.
  • Evaluation. Checkpoints every 5,000 steps; the final five are evaluated on held-out environment seeds with 256 rollouts each. Each run reports its best of the five; results are mean ± std over three training seeds.

05Analysis

Where does the gain come from, how should vision access the prior, and what does the prior retain after adaptation?

A1Latent vs. explicit transfer

How should visual observations connect to the frozen prior?

Latent transfer maps image features directly to the decoder’s context tokens. Explicit transfer instead predicts a privileged-shaped state and routes it through the frozen pretrained state encoder. Both use action-only supervision.

  • With the image encoder frozen, latent transfer beats the same architecture trained from scratch at every budget and threshold, so the gain cannot be explained by better visual features learned during adaptation. This supports the pretrained action prior as a key source of the data efficiency.
  • Latent transfer clearly outperforms explicit transfer across budgets under both thresholds.

Takeaway: Reusing the prior depends on how vision interfaces with it. Conditioning the decoder’s latent context directly gives higher success and more consistent training than explicit transfer.

A2What to adapt

Which modules should change during visual adaptation?

  • Conservative image-encoder updates improve strict success at every budget, while large updates degrade it, most strongly with 500 demonstrations.
  • Fine-tuning the action decoder brings no benefit at any tested scale; keeping it frozen is best under the strict criterion.

Takeaway: Adapt the image encoder conservatively and keep the action decoder frozen.

A3Robustness to unseen object mass

Does robustness acquired during RL pretraining survive visual adaptation?

RL pretraining randomizes object density, whereas each visual dataset contains a single object mass. Policies are evaluated on heavier objects without further training.

Takeaway: As mass increases, the RL-prior policy degrades more gradually than π0.5, despite using fewer demonstrations.

A4Contact-force information in the decoder

Do the decoder’s representations retain physical information learned through RL?

Linear ridge probes predict contact forces from the hidden state of each decoder layer of the adapted pose-alignment policy, using a separate force-annotated dataset. Lower RMSE means the force information is more linearly accessible. The comparison is a decoder of the same architecture trained from scratch.

06Limitations

  • The results concern downstream visual-demonstration efficiency, not total data or compute: the method relies on a capable privileged teacher and substantial simulated experience.
  • The frozen prior may inherit the teacher’s failure modes and restrict adaptation when new tasks require different control behaviors.
  • All tasks use the same arm–hand system. Bimanual transfer reuses the single-arm decoder and does not establish transfer to other robot morphologies.
  • Evaluation, including visual demonstration collection, is entirely in simulation; physical-robot performance is untested.
  • Mass robustness and force readout support the proposed interpretation but do not isolate a causal mechanism.
